Thanks for contacting Needless Goods Co. I can only answer from what's actually in the catalog — no making things up, no matter how tempting. Try asking about a product I couldn't possibly know about otherwise.
Engineering notes — embeddings: this build computes TF‑IDF vectors client‑side (no model download, no network dependency) so the retrieval math is fully inspectable; a larger catalog would call for a neural sentence-embedding model (e.g. all‑MiniLM‑L6‑v2) and an ANN index, but the surrounding loop — embed once, embed the query, score every chunk, keep the top‑k, hand them to the LLM — is identical. Generation: answers are produced by Gemini via a live API call using only the retrieved listings as context.
